## 联调中发现并修复的缺陷（E2E 价值）

1. **采集契约缺 session_id**（Go chatRequest 必填 vs collector 未发送）→ collector 每样本生成一次性 `eval-{uuid}` 会话
2. **中文提示词输出 shape 与 ragas 0.3.9 output_model 不匹配**（裸数组 vs 对象包裹）→ 四套提示词全部对齐 + `_unwrap()` 兼容 + PROMPT_VERSION 升 zh-v2
3. **ragas 0.3.9 instruction 不做 str.format**（占位符字面量直发模型）→ 删除模板占位符段 + 回归断言
4. **langchain embedding 发 token id 数组 + base64 编码**（ollama 等兼容端点 400）→ `check_embedding_ctx_length=False` + `encoding_format="float"`
5. **ragas 结果列名与规范指标名不一致**（`llm_context_precision_with_reference`）→ runner 列名归一化
6. embedder base_url 拼接约定（Go 自拼 /v1/embeddings）→ 部署文档注意：Go embedder 的 base_url 不带 /v1
