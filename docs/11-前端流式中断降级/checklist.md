# 前端流式中断降级 Checklist

> 每一项通过运行代码或观察行为来验证，聚焦系统行为。

## 实现完整性
- [ ] vitest 测试基建可用（验证：`cd frontend && npm test` 能运行测试文件）
- [ ] `chatStream` 解析各场景单测通过（验证：`npm test -- chat` 全绿）
- [ ] `chatStore` 降级状态机单测通过（验证：`npm test -- stores/chat` 全绿）
- [ ] 后端 SSE 对照用例（error / 空流）存在且通过（验证：`go test ./internal/api/ -v` 相关用例 ok）

## 降级行为（单测断言）
- [ ] error 事件 → 消息标记错误、内容为错误信息、`streaming` 复位（验证：stores/chat 用例 1）
- [ ] 用户停止 → 已输出内容保留、无错误标记、`streaming` 复位（验证：stores/chat 用例 2）
- [ ] 网络失败 → 消息显示可读错误、已有内容保留（验证：stores/chat 用例 3）
- [ ] 空流 → 内容为「（无回答）」、无错误标记（验证：stores/chat 用例 4）
- [ ] 正常流 → 内容完整、无错误、`streaming` 复位（验证：stores/chat 用例 5）
- [ ] 停止按钮状态：发送中可停止、结束后恢复（验证：stores/chat 用例 6 + ChatView 绑定）
- [ ] 非 2xx 响应 → 错误信息优先后端 message（验证：chat 用例 4）

## 集成
- [ ] 前端测试不破坏既有构建（验证：`cd frontend && npm run build` 通过）
- [ ] 后端 SSE 用例不回归既有行为（验证：`go test ./internal/api/...` 全绿）

## 编译与测试
- [ ] `cd frontend && npm test` 全部通过
- [ ] `cd frontend && npm run build` 通过
- [ ] `go build ./...` 通过
- [ ] `go test ./...` 通过
- [ ] `go vet ./...` 无告警

## 端到端场景（用户本机浏览器确认）
- [ ] 场景 1（error 事件）：真实问答中触发后端错误 → 消息显示错误、页面不崩（验证：浏览器操作 + DevTools 无未捕获异常）
- [ ] 场景 2（用户停止）：流式中点「停止」→ 已输出内容保留、按钮恢复发送（验证：浏览器操作）
- [ ] 场景 3（网络中断）：停后端/断网时提问 → 消息显示可读错误、不崩溃（验证：浏览器操作）
- [ ] 场景 4（空回答）：构造空流 → 显示「（无回答）」（验证：浏览器操作）
- [ ] 场景 5（控制台）：以上场景 DevTools Console 无未捕获异常（验证：浏览器 DevTools 观察）

## Spec 验收标准映射
- [ ] AC1（error 事件）→ 降级行为第 1 项 + 端到端场景 1
- [ ] AC2（停止保留内容）→ 降级行为第 2 项 + 端到端场景 2
- [ ] AC3（断网可读错误）→ 降级行为第 3 项 + 端到端场景 3
- [ ] AC4（非 2xx 信息）→ 降级行为第 7 项
- [ ] AC5（空流占位）→ 降级行为第 4 项 + 端到端场景 4
- [ ] AC6（无未捕获异常）→ 端到端场景 5
- [ ] AC7（08 checklist 勾选）→ 全部端到端场景通过后勾选
