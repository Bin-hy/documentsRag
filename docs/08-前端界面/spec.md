# 前端界面（Web + Wails 桌面）Spec

## 背景

BinRag 后端已完成：Gin 提供 RESTful API（知识库 CRUD、文档上传、异步入库任务、SSE 流式问答、对话历史、API Key 管理），但目前只有 HTTP 接口，没有面向用户的界面。

需要一个前端界面：既能在浏览器中以 Web 应用形式访问，又能打包为 macOS 等平台的桌面可安装应用，提供对话问答、知识库管理、文档上传、API Key 管理等完整操作体验。

## 目标

- 提供一套 Vue 3 + TypeScript 前端界面，覆盖对话问答、知识库管理、文档上传与任务管理、API Key 管理四大模块
- 同一套前端代码同时支持两种形态：浏览器 Web 应用、Wails 桌面应用
- 桌面安装包内嵌 Go 后端，安装后即为完整应用（数据库/向量库仍连接外部服务）
- 后端除「托管前端静态资源」外零逻辑改动

## 功能需求

- F1: 登录认证。用户输入 API Key 作为登录凭据，前端本地保存并附加到每个请求的 Authorization 头；未登录时只能访问登录页
- F2: 对话问答界面。支持选择知识库提问、SSE 流式输出（打字机效果）、引用来源展示（可点击定位）、多会话历史（新建/切换/删除会话）
- F3: 知识库管理。知识库的创建、编辑、删除、列表展示
- F4: 文档上传与任务管理。支持拖拽/选择上传多格式文档（TXT/Markdown/PDF/DOCX/CSV/Excel/HTML），展示解析入库任务状态与进度，失败任务可查看原因并手动重试，文档列表可删除
- F5: API Key 管理。API Key 的创建（明文仅展示一次，需用户手动复制）、启停切换、删除、列表展示（含最后使用时间）
- F6: Web 形态。前端构建产物由 Go 服务托管，`go build` 产出单一可执行文件，启动后浏览器访问即得完整界面
- F7: 桌面形态。通过 Wails 打包为 macOS 等平台可安装应用，应用内自动启动内嵌的 Go 后端并加载同一套前端界面

## 非功能需求

- N1: 全中文界面文案
- N2: 现代交互体验：Markdown 渲染与代码高亮、流式打字机效果、拖拽上传、任务进度反馈、加载态与错误提示、空状态引导
- N3: 响应式布局，适配桌面浏览器与窄屏窗口
- N4: 对话流式输出稳定：SSE 断线/异常有降级提示，不阻塞界面
- N5: 构建产物体积合理，Web 静态资源通过 Go embed 打包进二进制
- N6: 前端代码结构与后端解耦，仅通过 HTTP API 通信，不依赖 Wails 专有 API（便于浏览器调试与后续迁移）

## 不做的事

- 不改动后端业务 API（新增「托管静态资源」与「Wails 装配」除外）
- 不做用户名密码登录、JWT、RBAC 多用户权限
- 不做移动端原生应用
- 不做实时文档预览（Word/PDF 内容渲染）
- 不做系统设置页面（Embedder/LLM/检索参数等仍通过配置文件管理）

## 验收标准

- AC1: 未登录访问任意页面被引导到登录页；输入有效 API Key 后可进入全部功能页面；退出登录后回到登录页
- AC2: 对话界面可选择知识库提问，回答以流式打字机效果输出，引用来源以可点击卡片展示，会话可新建/切换/删除且历史消息正确恢复
- AC3: 知识库可创建、编辑、删除，列表实时反映操作结果
- AC4: 上传文档后任务进度可见，任务完成/失败状态正确展示，失败可查看原因并重试，文档可删除
- AC5: API Key 可创建（明文仅展示一次）、启停切换、删除，列表展示正确
- AC6: 前端构建产物被 Go 二进制托管：`go build` 产出单一可执行文件，浏览器访问默认地址即显示完整界面并可完成登录与问答
- AC7: Wails 桌面应用可打包启动，应用内完成登录、上传、问答全流程；关闭应用后进程干净退出
