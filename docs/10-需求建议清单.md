## B. 决策记录预留扩展位

### B1. 知识库级权限（API Key ↔ 知识库绑定）
- **建议内容**：API Key 与知识库绑定，key 只能访问指定 kb_id 范围（接口与检索均过滤）。
- **依据**：`docs/06-api/决策记录.md`「选定 B（静态 API Key）…预留与知识库绑定的扩展位（后续可限制 key 只访问指定 kb_id）」。
- **优先级**：P1（多知识库共享服务时安全刚需）

### B2. 任务调度层替换为 Asynq
- **建议内容**：入库任务调度从 goroutine pool 升级为 Asynq 消息队列，支持分布式 worker、延迟重试、优先级。
- **依据**：`docs/06-api/决策记录.md`「后续规模扩大再把任务调度层替换为 Asynq，业务处理逻辑不变」。
- **优先级**：P2

### B3. 对象存储替换本地磁盘
- **建议内容**：上传文件存储从本地磁盘迁移到 S3/OSS 等对象存储。
- **依据**：`docs/06-api/决策记录.md`「文件存本地磁盘，后续可替换为 S3/OSS 等」。
- **优先级**：P2
